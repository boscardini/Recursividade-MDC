# Sobre o Projeto

Este repositório apresenta uma solução simples e prática em Java para demonstrar o conceito de recursividade aplicado ao cálculo do Máximo Divisor Comum (MDC) entre dois números inteiros.

## Como Funciona

A lógica baseia-se em encontrar o maior divisor comum utilizando subtrações sucessivas e trocas de posição até que os dois valores se igualem. Por exemplo, ao calcular o MDC entre *20* e *24*
